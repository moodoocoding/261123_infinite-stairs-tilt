# 무한의 계단 · 기울기 센서 게임

2026-11-23 생성. 갤럭시 스마트폰·태블릿을 좌우로 기울여 계단을 오르는 게임입니다.

- [게임 실행 · Vercel](https://2026-11-23-infinite-stairs-tilt.vercel.app/)
- [GitHub 저장소 · 261123_infinite-stairs-tilt](https://github.com/moodoocoding/261123_infinite-stairs-tilt)

화면 스타일, 캐릭터와 계단, 게임 로직, 센서 처리, 효과음이 **index.html 한 파일**에 들어 있습니다. 외부 라이브러리·폰트·이미지·음원 다운로드가 필요하지 않습니다.

공용 리더보드는 별도의 Vercel 서버 API와 서버 저장소를 사용하므로 온라인 게임 주소에서 이용합니다. HTML 파일만 다운로드해서 실행하면 기기 내 게임은 실행할 수 있지만 공용 순위를 저장하거나 조회할 수 없습니다.

## 세계 공용 리더보드

- 시작 화면·결과 화면의 **세계 공용 순위표**에서 전 세계 공통 기록 상위 50명을 확인합니다.
- 1층 이상 오른 게임이 끝난 뒤 닉네임(2~12자)을 입력하고 **이번 점수 등록**을 누릅니다. 등록한 닉네임과 점수는 공개됩니다.
- 같은 브라우저의 서명된 참가자 쿠키를 기준으로 최고 점수 한 개를 유지합니다. 닉네임이 같아도 다른 기기의 기록은 별도 참가자입니다. 계정 로그인이 없으므로 다른 기기로 개인 기록을 합치지는 않습니다.
- 같은 층수는 공동 순위입니다. 기기 내 최고 기록은 기존대로 별도로 유지하며 과거 로컬 기록을 서버에 자동 업로드하지 않습니다.
- 저장 실패·통신 지연은 화면에 알리고 재시도할 수 있습니다. 샘플 순위를 실제 기록처럼 표시하지 않습니다.

### 서버 저장 방식

Vercel Functions의 `/api/leaderboard`와 Firebase **261123 leadder** 프로젝트의 **Cloud Firestore**를 사용합니다. 프로젝트 ID는 `leadder-d2ca1`이며, Firestore와 함수는 서울 리전을 사용합니다. 브라우저가 DB에 직접 접근하지 않고 서버 API가 공개 순위 필드만 반환합니다.

Firestore의 `stairsLeaderboard` 컬렉션에 순위 문서와 서버 서명 키를 보관합니다. 읽기는 서버 SDK로 최신 내용을 조회하고, 쓰기는 문서 updateTime 조건부 갱신과 충돌 재시도로 동시 등록에 의한 덮어쓰기를 방지합니다. 서명 키와 참가자 ID는 공개 응답에 포함하지 않습니다. 브라우저 보안 규칙은 직접 읽기·쓰기를 차단하며 서버 전용 서비스 계정의 IAM 권한으로만 접근합니다.

서버 인증은 Vercel OIDC와 Google Workload Identity Federation을 사용합니다. Google Cloud에서 계단 게임의 Vercel 프로젝트만 허용하도록 전용 공급자와 서비스 계정을 연결한 뒤 배포해야 합니다. 서비스 계정 키 파일·비공개 키는 발급하거나 HTML·GitHub에 넣지 않습니다. 다른 Firebase 프로젝트 또는 다른 프로젝트의 서비스 계정은 코드에서 거부합니다. Firestore 접근 권한이 없는 경우 다른 저장소에 기록한 뒤 성공했다고 응답하지 않습니다.

Vercel 환경 변수는 `FIREBASE_PROJECT_ID=leadder-d2ca1`, `GCP_PROJECT_NUMBER`, `GCP_SERVICE_ACCOUNT_EMAIL`, `GCP_WORKLOAD_IDENTITY_POOL_ID`, `GCP_WORKLOAD_IDENTITY_POOL_PROVIDER_ID`이며 모두 연결 위치를 나타내는 설정입니다. 짧은 수명의 OIDC 토큰은 요청할 때 Vercel이 제공합니다.

기존 Blob 저장소에 기록이 있으면 Firestore 문서가 비어 있을 때 한 번만 복사합니다. 참가자 쿠키를 검증하는 기존 서명 키도 함께 이전하므로 기존 사용자의 최고 기록을 유지합니다. Blob 의존성은 이 이전용 읽기에만 사용하고, 새 기록은 Firestore에 저장합니다.

프로덕션과 미리보기는 별도 문서에 기록합니다. 최고 기록 상위 1,000개를 보관하고 그중 50개를 표시합니다. 한 문서가 Firestore 크기 제한에 도달하지 않도록 등록 영수증과 문서 크기를 제한합니다. 게임 시작 시 서버가 발급한 서명 티켓, 점수 형식·시간·코인 범위, 중복 등록 등을 검사합니다. 이는 기본 검증이며 브라우저 게임의 모든 입력을 서버에서 재현하는 완전한 부정행위 방지는 아닙니다.

## 실행

기울기 조작은 Vercel로 배포된 **HTTPS 게임 주소**를 Chrome 또는 삼성 인터넷에서 직접 열어 실행합니다. 다운로드한 HTML을 파일 앱에서 열면 Android의 content:// 등의 실행 환경에서 센서 이벤트가 전달되지 않을 수 있습니다. HTML을 하나로 묶는 것과 브라우저가 센서 접근을 허용하는 것은 별개입니다.

1. 게임 시작을 누르고 센서 권한이 표시되면 허용합니다.
2. 기기를 편하게 잡고 잠시 멈추면 그 자세가 0°로 보정됩니다.
3. 좌우로 약 9° 이상 기울이면 해당 방향 계단으로 이동합니다. 유지하면 연속 이동합니다.
4. 잡는 자세를 바꾸면 기준 자세 맞추기를 누릅니다.

화면의 방향 버튼, 화면 탭·스와이프, 키보드 좌우 화살표도 사용할 수 있습니다. 다음 계단이 없는 방향으로 움직이면 추락합니다.

## 센서 처리

브라우저의 방향 센서 값을 우선 사용하고, 방향 값이 수신되지 않을 때 중력 가속도 값을 사용합니다. 화면 회전 보정, 시작 자세 보정, 흔들림 완화, 신호 끊김에 따른 입력 중단을 포함합니다.

HTTPS에서도 센서 신호가 없다면 브라우저의 동작 센서 접근 허용과 앱 내 브라우저 여부를 확인합니다. 센서 차단 환경을 코드로 우회하지 않습니다.
